# NUK RentServe React migration

The static `NUKFrontend-main` folder was replaced in this distribution by `NUKFrontend-react`. The existing `NUKBackend-main` folder is preserved. See `NUKFrontend-react/README.md` for setup and known API gaps.

Important: transport vehicle listings, admin driver/vehicle approvals, booking accept/reject, and enquiry chat require backend implementation; they are not present in the backend archive and are not represented as complete features in this frontend.
